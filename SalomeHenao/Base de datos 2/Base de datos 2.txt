a) Descripción general
Nombre de la base de datos
•Cardiovascular Disease dataset
¿Qué es la base de datos? (tema, contexto y propósito)
•The dataset consists of 70,000 records of patients data, 11 features and target. Its purpose is to analyze and predict the presence or absence of cardiovascular disease (cardio, binary target variable) based on three types of input features:
Objective: factual information 
Examination: results of medical examination 
Subjective: information given by the patient 
¿Cómo se obtuvieron los datos? (encuesta, sensores, scraping, registros administrativos, etc.)
•All of the dataset values were collected at the moment of medical examination, combining clinical examination results with patient-reported lifestyle information.
Fuente / URL de descarga
• Kaggle / https://www.kaggle.com/datasets/sulianova/cardiovascular-disease-dataset/data
Número de filas y columnas
•Filas: 70000 y Columnas: 13
Formato del archivo (CSV, Excel, JSON, etc.)
• Excel
b) Descripción de Columnas

1. id | Data Type: int64 | Role: Identifier | Description: Unique patient record ID.
2. age | Data Type: int64 | Role: Objective Feature | Description: Age of the patient measured in days.
3. gender | Data Type: int64 | Role: Objective Feature | Description: Gender of the patient (categorical code: 1 / 2).
4. height | Data Type: int64 | Role: Objective Feature | Description: Height of the patient in centimeters (cm).
5. weight | Data Type: float64 | Role: Objective Feature | Description: Weight of the patient in kilograms (kg).
6. ap_hi | Data Type: int64 | Role: Examination Feature | Description: Systolic blood pressure.
7. ap_lo | Data Type: int64 | Role: Examination Feature | Description: Diastolic blood pressure.
8. cholesterol | Data Type: int64 | Role: Examination Feature | Description: Cholesterol level of the patient (1: normal, 2: above normal, 3: well above normal).
9. gluc | Data Type: int64 | Role: Examination Feature | Description: Glucose level of the patient (1: normal, 2: above normal, 3: well above normal).
10. smoke | Data Type: int64 | Role: Subjective Feature | Description: Whether the patient smokes or not (0: No, 1: Yes).
11. alco | Data Type: int64 | Role: Subjective Feature | Description: Whether the patient consumes alcohol (0: No, 1: Yes).
12. active | Data Type: int64 | Role: Subjective Feature | Description: Whether the patient engages in physical activity (0: No, 1: Yes).
13. cardio | Data Type: int64 | Role: Target | Description: Target variable: Presence (1) or absence (0) of cardiovascular disease.
